# 기능 명세서

기준: 2026-02-06

| 대분류 | 기능 | 세부 기능/규칙 | 사용자 관점 |
| --- | --- | --- | --- |
| 회원관리 | 로그인 | 아이디(이메일)와 비밀번호 일치 여부 확인<br>로그인 성공 시 Access/Refresh Token 발급 및 저장 | 사용자가 아이디와 비밀번호를 입력해 로그인할 수 있다. |
| 회원관리 | 로그아웃 | 로그아웃 요청 시 토큰 삭제 처리 | 사용자가 시스템에서 로그아웃할 수 있다. |
| 회원관리 | 회원가입 | 이메일(ID), 비밀번호, 닉네임, 이름, 생년월일 입력<br>비밀번호 최소 8자 검증<br>회원 정보 저장 | 사용자가 기본 정보를 입력해 회원가입할 수 있다. |
| 회원관리 | 토큰 재발급 | Refresh Token 유효성 검증<br>Access Token 재발급 | 사용자가 앱을 재실행해도 로그인 상태를 유지할 수 있다. |
| 회원관리 | 소셜 로그인 | 카카오/구글/네이버/애플 계정 연동<br>최초 로그인 시 회원 정보 자동 생성 | 사용자가 소셜 계정을 통해 간편하게 로그인할 수 있다. |
| 회원관리 | 마이페이지 | 사용자 기본 정보 조회<br>닉네임/이름/생년월일 수정 | 사용자가 자신의 회원 정보를 확인하고 수정할 수 있다. |
| 회원관리 | 건강정보 관리 | 당뇨 유형(1/2/당뇨 전/기타) 선택<br>진단 연/월, 성별, 키, 몸무게 등록/수정 | 사용자가 자신의 건강 정보를 등록하고 수정할 수 있다. |
| 회원관리 | 프로필 이미지 | 프로필 이미지 업로드/변경<br>프로필 이미지 삭제 | 사용자가 자신의 프로필 이미지를 관리할 수 있다. |
| 회원관리 | 비밀번호 변경 | 현재 비밀번호 검증<br>새 비밀번호(8자 이상) 등록 | 사용자가 비밀번호를 변경할 수 있다. |
| 회원관리 | 회원탈퇴 | 탈퇴 요청 처리 및 사용자 데이터 삭제 | 사용자가 서비스 이용을 종료할 수 있다. |
| CGM 연동 | Dexcom OAuth 연결 | OAuth authorize URL 발급/리다이렉트<br>OAuth 콜백 처리 | 사용자가 Dexcom 계정을 연동할 수 있다. |
| CGM 연동 | Dexcom 토큰 관리 | Access Token 저장<br>Refresh Token으로 토큰 갱신 | 사용자의 Dexcom 연동을 유지할 수 있다. |
| CGM 연동 | Dexcom 연동 해제 | 토큰 폐기 및 연동 해제<br>옵션에 따라 연동 데이터 삭제 | 사용자가 Dexcom 연동을 해제할 수 있다. |
| CGM 연동 | Dexcom 데이터 범위 조회 | 데이터 범위 조회 API 제공 | 사용자가 연동 상태를 확인할 수 있다. |
| CGM 연동 | Dexcom EGV 조회 | 지정 기간 EGV(혈당) 데이터 조회 | 사용자가 혈당 데이터를 가져올 수 있다. |
| 센서/혈당 | 활성 센서 조회 | 현재 활성 센서 정보 조회 | 사용자가 현재 사용 중인 센서를 확인할 수 있다. |
| 센서/혈당 | 센서 이력 조회 | 센서 사용 이력 조회 | 사용자가 이전 센서를 확인할 수 있다. |
| 센서/혈당 | 실시간 혈당 그래프 | 기간 지정 조회(start/end)<br>기본 24시간, 최대 7일 제한 | 사용자가 실시간 혈당 흐름을 확인할 수 있다. |
| 센서/혈당 | 목표 범위 제공 | 기본 70~140, 당뇨 유형에 따라 상한 조정 | 사용자가 목표 범위를 참고할 수 있다. |
| 식사 기록 | 식사 기록 생성 | 사진/음식명/탄수화물/무게/섭취량/식사유형/섭취시간/메모 입력 | 사용자가 식사 기록을 등록할 수 있다. |
| 식사 기록 | 식사 기록 목록 | 전체 식사 기록 조회 | 사용자가 전체 기록을 볼 수 있다. |
| 식사 기록 | 기간별 조회 | 시작/종료일 기준 조회 | 사용자가 기간별 기록을 볼 수 있다. |
| 식사 기록 | 상세 조회 | 특정 식사 기록 조회 | 사용자가 상세 정보를 확인할 수 있다. |
| 식사 기록 | 기록 수정 | 식사 정보 수정 | 사용자가 식사 기록을 수정할 수 있다. |
| 식사 기록 | 이미지 수정 | 식사 이미지 변경 | 사용자가 식사 사진을 수정할 수 있다. |
| 식사 기록 | 기록 삭제 | 식사 기록 삭제 | 사용자가 기록을 삭제할 수 있다. |
| AI | 음식 사진 분석 | 사진 기반 음식 인식 및 영양/탄수화물 추정 | 사용자가 음식 사진으로 분석을 받을 수 있다. |
| AI | AI 가이드 생성 | 비동기 가이드 생성 요청<br>가이드 상태/결과 조회 | 사용자가 개인화 가이드를 받을 수 있다. |
| AI | 혈당 반응 예측 | 식사 기반 혈당 반응 예측 그래프 제공 | 사용자가 식사 후 혈당 흐름을 예상할 수 있다. |
| 리포트 | 일일 리포트 최신 | 최신 일일 리포트 1건 조회 | 사용자가 오늘 리포트를 확인할 수 있다. |
| 리포트 | 리포트 히스토리 | 센서별 일일 리포트 조회 | 사용자가 지난 리포트를 확인할 수 있다. |
| 리포트 | 기간별 혈당 리포트 | 기간별 혈당 요약 및 TIR 제공 | 사용자가 기간별 분석을 확인할 수 있다. |
| 리포트 | 요약 텍스트 | 리포트 요약/브리핑 텍스트 제공 | 사용자가 요약 코멘트를 확인할 수 있다. |
| 알림 | 푸시 토큰 등록 | 디바이스 푸시 토큰 등록 | 사용자가 푸시 알림을 받을 수 있다. |
| 알림 | 알림 목록 | 전체/미읽음 알림 조회 | 사용자가 알림 목록을 확인할 수 있다. |
| 알림 | 알림 읽음 처리 | 개별 알림 읽음 처리 | 사용자가 알림을 읽음 처리할 수 있다. |
| 알림 | 알림 전체 읽음 | 알림 전체 읽음 처리 | 사용자가 알림을 일괄 처리할 수 있다. |
| 알림 설정 | 알림 설정 조회 | 알림 유형별 설정 목록 조회 | 사용자가 알림 설정을 확인할 수 있다. |
| 알림 설정 | 알림 설정 변경 | 유형별 on/off, 임계값, 반복 간격 설정 | 사용자가 알림 조건을 조정할 수 있다. |
| 운영/테스트 | 과거 데이터 수집 | 지정 일수(days) 기준 CGM 과거 데이터 수집 | 운영자가 데이터 동기화를 수행할 수 있다. |
| 운영/테스트 | 최신 데이터 수집 | 특정 사용자 최신 CGM 데이터 수집 | 운영자가 최신 데이터를 갱신할 수 있다. |
