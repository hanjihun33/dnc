# 시연 시나리오 (DEMO_SCENARIO)

## 시나리오 개요: "당낭콩 - AI 음식이미지 분석 기반 당뇨관리 Assistant"
사용자가 아침에 일어나 혈당을 확인하고, 식사를 기록하며 AI 분석을 받고, 하루를 리포트로 마무리하는 흐름입니다.

---

## 단계별 상세 시나리오

### 1. 앱 실행 및 로그인 (Auth)
- **화면**: `(auth)/login` (로그인 화면)
- **Action**: 카카오/구글/네이버 로그인 버튼 중 하나 클릭.
- **Back-Logic**: `SocialLoginController`가 동작하여 OAuth 인증 후 JWT 토큰 발급.
- **Transition**: 로그인 성공 시 메인 화면(`(tabs)/index`)으로 이동.

### 2. 메인 대시보드 확인 (Home)
- **화면**: `(tabs)/index` (홈)
- **주요 기능**:
    1. **현재 혈당 확인**: 최상단 원형 그래프에서 현재 혈당값(예: 120 mg/dL) 및 추세 확인.
    2. **AI 브리핑**: "오늘 혈당이 안정적이네요!" 등의 AI 코멘트 확인 (`DailySummaryCard`).
    3. **최근 식사**: 하단 리스트에서 최근 기록한 식사 내역 확인.

### 3. 식사 기록 및 AI 분석 (Meal & AI)
- **화면**: `(tabs)/meal` (식사 탭) -> `(tabs)/meal-camera`
- **Action 1**: 하단 네비게이션 'AI식단분석' 탭 클릭.
- **Action 2**: '카메라로 촬영' 버튼 클릭 (시연 시 더미 이미지나 앨범 선택 가능).
- **Action 3**: 음식 사진 업로드.
- **Back-Logic**:
    - 앱이 이미지를 S3에 업로드.
    - **1단계 (Vision AI)**: `YOLO`가 음식 종류를 탐지하고, `ResNet`이 양(Quantity)을 추정합니다.
    - **2단계 (Generative AI)**: 분석된 영양 정보를 바탕으로 `Gemini-2.5-pro`가 맞춤형 식단 가이드(코멘트)를 생성합니다.
    - **3단계 (Simulation)**: 섭취 영양소와 환자 상태를 기반으로 `SciPy` 기반 생리학적 모델(Physiological Model)이 식후 혈당 변화를 예측합니다.
- **Result**: 분석 결과 화면(`meal-detail` 또는 `meal-edit`) 출력.
    1. **음식 정보**: "현미밥(300kcal), 된장국(80kcal)" 등 자동 입력된 정보 확인.
    2. **혈당 예측**: 식후 2시간 동안의 혈당 변화 그래프(Simulation Model) 확인.

### 4. 리포트 조회 (Report)
- **화면**: `(tabs)/report` (리포트 탭)
- **Action**: 하단 네비게이션 '리포트' 탭 클릭.
- **Check Point**:
    1. **TIR 그래프**: 목표 범위 내 비율(Time In Range) 파이 차트 확인.
    2. **일일 변동성**: 그래프가 평탄한지, 요동치는지 시각적으로 확인.
    3. **데이터 연동 확인**: `ReportController`의 `/api/v1/reports/daily/latest` API가 호출되어 어제/오늘의 분석 데이터가 로딩되는지 확인.

### 5. 설정 및 센서 연결 (Settings)
- **화면**: `(tabs)/settings` (설정 탭)
- **Action**: '센서 연결' 메뉴 클릭 -> 'Dexcom 연결하기' 클릭.
- **Scenario**: 샌드박스 로그인 페이지로 이동 -> 로그인 승인 -> 앱으로 복귀하며 "센서 연결 성공" 메시지 확인.

---

## 시연 시 유의사항 (Pre-check)
1. **데이터 준비**: 시연 전 `ReportController`의 테스트 API(`/api/v1/reports/test/generate`)를 호출하여 더미 리포트 데이터를 생성해두면 풍성한 화면을 보여줄 수 있습니다.
2. **센서 상태**: 센서 미연결 상태일 경우 홈 화면에 "센서를 연결해주세요" 문구가 뜰 수 있으므로, 시연 목적에 따라 사전에 연결 상태를 DB에 세팅해두는 것이 좋습니다.
3. **이미지 로딩**: 로컬 이미지와 S3 이미지 경로가 혼재될 수 있으므로, 외부 인터넷 연결 상태를 반드시 확인하세요 (S3 이미지 로딩용).
